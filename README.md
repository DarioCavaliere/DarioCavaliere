# Dado – Easy Recipes for Every Taste & Mood

A recipe-sharing website. Find recipes by mood, kitchen or look, and share your own.

## Files

- `index.html`: the main version, published at https://claude.ai/artifact/VhynFGdjLtdh9WqmLsCivD
- `version-b.html`: the alternative "version B" look (bold outlines, flat candy colours), published at https://claude.ai/artifact/X3AAwoF2R3txPAbgE6kZjL

Each page is a single self-contained HTML file. Open it in a browser to view it.

## Notes for continuing work

- The main version stores shared recipes, sign-in and photo uploads through the Claude Artifact runtime (`window.claude`). Those features only work on the published artifact. Opened as a local file, the page still shows the built-in recipes.
- To update the live pages, ask Claude to republish `index.html` (or `version-b.html`) to the artifact links above.
- Work in progress lives on the branch `claude/exciting-sagan-owdanl`.
